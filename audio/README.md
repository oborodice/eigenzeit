# audio

```bash
# 音を出すサーバーを起動し、OSCを待ち受けて、マイクの特徴量を送る(入出力はOSの既定の機器でマイクは入力1、Ctrl+Cで終了)
$ /Applications/SuperCollider.app/Contents/MacOS/sclang main.scd
```

- `main.scd` : 起動し、各層を読み込んで、層の合計を抑えてから出力する。マイクの特徴量をPythonへ送る
- `sines.scd` : サイン波の層
- `clicks.scd` : クリックの層
- `noise.scd` : ノイズの層
- `mic.scd` : マイクの音から特徴量を取り出す

## 受信するOSC

- 通信: UDP、ポート57120
- 値は全て0〜1で送る(範囲外の値は0〜1に収める)
- 音量は、0〜1を-60〜0dBに対応させる(0は無音)
- 新しい値には、2秒かけて滑らかに移る
- 起動直後はどの層も音量0で、無音
- `/sines/1` 、 `/sines/2` : サイン波を重ね合わせて鳴らす(同じ層が2つあり、それぞれ別々に鳴らせる)
  - 1つ目の値: 基準の周波数(55Hz〜20kHzに対数で対応)
  - 2つ目の値: 本数(1〜8本、端数の分はその音量で鳴らす)
  - 3つ目の値: 広がり(隣り合うサイン波の間隔、0.0005〜1オクターブに対数で対応)
  - 4つ目の値: ずれ方(等間隔からランダムへ)
  - 5つ目の値: 高さの揺れの速さ(1秒に0.1〜5回に対数で対応)
  - 6つ目の値: 高さの揺れの深さ(上下それぞれ0.001〜1オクターブに対数で対応。全てのサイン波を同じだけ揺らす)
  - 7つ目の値: 音量
- `/clicks` : クリックを鳴らし続ける
  - 1つ目の値: 頻度(1秒に0.1〜20000回に対数で対応)
  - 2つ目の値: 不規則さ(等間隔からランダムへ)
  - 3つ目の値: 明るさ(クリック1回の揺れの周波数、55Hz〜20kHzに対数で対応)
  - 4つ目の値: 音量
- `/noise` : ホワイトノイズから、帯域を選んで鳴らし続ける
  - 1つ目の値: 帯域の中心(55Hz〜20kHzに対数で対応)
  - 2つ目の値: 帯域の幅(0.01〜10オクターブに対数で対応、狭いと音の高さを持ち、広いとザーッという音になる)
  - 3つ目の値: 音量(幅を変えても、音の大きさが揃うように補う)

## 送信するOSC

- 通信: UDP、送り先は127.0.0.1のポート9000
- `/mic` : マイクの特徴量を、1秒に10回送る
  - 値は1つの文字列で、名前を付けたJSONのオブジェクト

```json
{"band_rel_db": [-23.1, ..., -41.8], "total_db": -54.6, "flatness": 0.0123, "onset_count": 0}
```

- `band_rel_db` : 1/3オクターブの帯域ごとの大きさ(中心63Hz〜20kHzの26個、低い順)を、全体の大きさとの差で表した値(dB、小数第2位まで)
- `total_db` : 全体の大きさ(dB、小数第2位まで)
- `flatness` : ノイズっぽさ(0〜1、高さのある音ほど0、ノイズほど1に近い。小数第4位まで)
- `onset_count` : 前に送ってから今までに、音が急に立ち上がった回数
