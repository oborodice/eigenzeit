# audio

```bash
# 音を出すサーバーを起動し、OSCを待ち受ける(出力先はOSの既定の出力、Ctrl+Cで終了)
$ /Applications/SuperCollider.app/Contents/MacOS/sclang main.scd
```

- `main.scd` : 起動し、各層を読み込んで、層の合計を抑えてから出力する
- `sines.scd` : サイン波の層
- `clicks.scd` : クリックの層
- `noise.scd` : ノイズの層

## 受信するOSC

- 通信: UDP、ポート57120
- 値は全て0〜1で送る(範囲外の値は0〜1に収める)
- 新しい値には、2秒かけて滑らかに移る
- 起動直後はどの層も音量0で、無音
- `/sines/1` 、 `/sines/2` : サイン波を重ね合わせて鳴らす(同じ層が2つあり、それぞれ別々に鳴らせる)
  - 1つ目の値: 基準の周波数(55Hz〜20kHzに対数で対応)
  - 2つ目の値: 本数(1〜8本、端数の分はその音量で鳴らす)
  - 3つ目の値: 広がり(隣り合うサイン波の間隔、0.0005〜1オクターブに対数で対応)
  - 4つ目の値: ずれ方(等間隔からランダムへ)
  - 5つ目の値: 音量
- `/clicks` : クリックを鳴らし続ける
  - 1つ目の値: 頻度(1秒に0.1〜20000回に対数で対応)
  - 2つ目の値: 不規則さ(等間隔からランダムへ)
  - 3つ目の値: 明るさ(クリック1回の揺れの周波数、55Hz〜20kHzに対数で対応)
  - 4つ目の値: 音量
- `/noise` : ホワイトノイズから、帯域を選んで鳴らし続ける
  - 1つ目の値: 帯域の中心(55Hz〜20kHzに対数で対応)
  - 2つ目の値: 帯域の幅(0.01〜10オクターブに対数で対応、狭いと音の高さを持ち、広いとザーッという音になる)
  - 3つ目の値: 音量(幅を変えても、音の大きさが揃うように補う)
