# audio

```bash
# 音を出すサーバーを起動し、OSCを待ち受ける(出力先はOSの既定の出力、Ctrl+Cで終了)
$ /Applications/SuperCollider.app/Contents/MacOS/sclang main.scd
```

## 受信するOSC

- 通信: UDP、ポート57120
- 値は全て0〜1で送る(範囲外の値は0〜1に収める)
- 新しい値には、10秒かけて滑らかに移る
- `/sines` : サイン波を重ね合わせて鳴らす(起動直後は音量0で、無音)
  - 1つ目の値: 基準の周波数(55Hz〜20kHzに対数で対応)
  - 2つ目の値: 本数(1〜8本、端数の分はその音量で鳴らす)
  - 3つ目の値: 広がり(隣り合うサイン波の間隔、0.0005〜1オクターブに対数で対応)
  - 4つ目の値: ずれ方(等間隔からランダムへ)
  - 5つ目の値: 音量
